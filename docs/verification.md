## 复验

USB 调试连接后先确认设备状态，再安装当前公开发布包：

```sh
adb devices -l
adb -s <设备> install --no-streaming -r dist/jianlan-0.2.2.apk
```

旧版 0.2.1 使用调试签名，不能直接被 0.2.2 发布签名覆盖；卸载旧版会清除原有登录状态与设置。

使用无线调试时，读取手机无线调试页显示的当前连接端口（与配对端口不同）：

```sh
adb connect <当前IP:连接端口>
adb -s <设备> install --no-streaming -r dist/jianlan-0.2.2.apk
```

截图与临时验收记录保存在被 Git 忽略的 `dist/qa/`；本轮小米证据目录为 `dist/qa/v0.2.2-xiaomi/`。双屏设备截图需明确选择实际测试的物理 display。含私人浮层的截图不上传，公开记录不包含设备序列号、配对码、Cookie 或账号凭证。
